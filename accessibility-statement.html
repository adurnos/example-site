Accessibility

Demo page

This fictional plumbing website is designed to be usable on phones, tablets, and computers. It uses semantic page sections, labeled form controls, keyboard-accessible navigation, visible focus styles, responsive layouts, and reduced-motion preferences.

Feedback

If you encounter a barrier in this demo, the contact information on the home page is fictional and is not monitored. For a real deployment, replace it with an accessible way to report an issue and request assistance.
